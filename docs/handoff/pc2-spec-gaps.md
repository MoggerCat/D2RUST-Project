unspecified / no spec yet / Pending / TODO(spec" line in the PC 2 specs
(objects, hirelings, all quests, UI except `ui/text.md`, audio, `wav`,
`d2s`, `items/*`, `world/{vendors,cube,npc,waypoints}`, plus
`client/{ui,audio}.md`). Generated by a script, then grouped in the work
order of the PC 2 brief.

**Classes are heuristic.** "Binary" = no recording / capture / trace /
packet / R<n> / V<n> wording in the item; "recording" = such wording.
Items already marked answered, struck, or pointing to the section that now
holds the answer are left out. Cost of a binary item from the number of
distinct 1.14d addresses it names: **S** one (≈ 1 Ghidra read), **M** two,
**L** none or three or more (find the site first; per the brief, an item
that needs more than two reads moves to the recording list). Each item is
confirmed or reclassified when its area is worked; the area report says so.

Deliverables outside this list: `ui/controls.md` and `ui/inventory.md`
(do not exist yet); the second pass on `render/shading.md`,
`render/blend-modes.md`, `render/lighting.md`, `audio/triggers.md`,
`ui/panels.md`; `xpc-to-pc2.md` open line 1 (`world/cube.md` §1, 0x77 is
`sim`); message rows 0x2A, 0x50, 0x58, 0x63 to `xpc-to-pc1.md` (0x58 is
