Generated by `tools/coverage-map/report.py` 0.1.0 from the `coverage-map 1`
counters of a d2-sim built with `--features coverage-map`; the tables are the
install's (Patch_D2 > d2exp > d2data excel). Runs merged:

Runs (2026-10-09, cloud, branch `claude/q-tool-coverage-perf`, real 1.14d install):
`playthrough` = `tools/playthrough/playthrough.py --all` (49 of 73 milestones reached);
`checks` = the d2rs side of all 27 `traces/checks/*.check` (`scenario_diff.py --d2rs-only
--channels state`, no Wine); `gametests` = the `#[ignore]` game-file tests of d2-server
(18 pass, 1 red: `game_town_run::town_run_moves_at_the_run_velocity`, 4899 vs 4901),
conformance, scenario-run, seed-finder and d2s-tool. **Not in this map:** the d2-sim
game-file tests (rustc SIGSEGV building the release lib tests, environmental, not
retried) and the d2-client game-file tests (a staging merge landed mid-build; rerun with
`cargo test -p d2-client --release --features d2-sim/coverage-map -- --ignored`).

## Where untested bugs hide (read first)

1. **No object was ever operated** in any run (0 of 431 operable rows: chests,
   doors, shrines, wells, waypoints, portals). Every object operate path
   (`world::objects::dispatch` and its callers) is unexercised on real data. The
   playthrough cannot click objects yet; a `--poke`/input that operates the
   nearest chest, shrine and waypoint per act would close the biggest gap.
2. **NPC dialogue is almost untouched** (1 of 47 interacting NPCs, only through a
   test): the playthrough cannot talk (`playthrough.md` Open question 3), so
   every quest step that needs a talk (Den of Evil, Sisters, Radament, ...) and
   every vendor / healer / hireling menu is untested in runs.
3. **Player skills: 15 of 357 started or done**; every class's level-1 skills
   (Magic Arrow, Fire Bolt, Teeth, Jab, ...) are never cast in a run. Missiles
   (15 created) and states (5 applied) follow from that.
4. **Monsters: 172 classes created, 277 spawnable classes never**, starting in
   Cold Plains / Stony Field (corrupt rogues, foul crows, quill rats 2, brutes 2);
   33 monster AI types never ran (CorruptLancer, FallenShaman, BloodHawk,
   FoulCrowNest, SkeletonBow first).
5. **Items: 36 of 659 base items created** (few drops, no vendor stock in runs);
   stamina / antidote potions, identify scrolls and books, keys and every gem were
   never created; low, crafted and tempered quality never.
6. **Quests: 13 slots touched; Act I completion (7), Search for Cain (4),
   Tools of the Trade (3) and most of Acts II-III never set** in a run.

Counters are in d2-sim behind the off-by-default `coverage-map` feature
(`specs/tools/coverage-map.md`); state records were byte-identical with the
feature on and off (`combat-arrow-kill`, `milestone-baal-throne`). Regenerate:
build `d2-client` with `--features coverage-map`, run with
`D2_COVERAGE_DIR=DIR`, then `python3 tools/coverage-map/report.py --excel
<Patch_D2,d2exp,d2data excel dirs> --run NAME=DIR ... --md docs/handoff/coverage-map.md`.
