# PC 2 recording list: items / inventory lane (`claude/pc2-items`)

Pointer: questions of `specs/items/*`, `specs/formats/d2s*.md` that need a recording, capture or sample file instead of more Ghidra reads (2026-10-07). The coordinator merges these into HANDOFF §7.

Recorder commands are those of `docs/LOCAL-RUN.md` (`tools/trace-recorder`, `tools/d2s_check.py`). Saves live in `%USERPROFILE%\Saved Games\Diablo II`; copy them read-only, never into the repo.
